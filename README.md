# Nexus Pro - Virtual Watch Try-On

**Nexus Pro** is a premium, web-native Virtual Try-On (VTO) solution for luxury watches. It uses real-time hand tracking and 3D rendering to provide an immersive boutique experience across desktop and mobile.

## 🚀 Key Features
- **Accurate Wrist Tracking**: Powered by MediaPipe for precise anatomical placement.
- **Desktop-Mobile Sync**: Seamless bridge from desktop to mobile camera via QR.
- **High-Res 3D Rendering**: Three.js-based visualization with customizable lighting and shadows.
- **Chroma-Key Separation**: Dynamic background removal for studio product shots.

## 🛠️ Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
